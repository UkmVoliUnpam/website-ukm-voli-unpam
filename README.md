# UKM Voli UNPAM — Website Gratis

Website landing page responsif untuk UKM Bola Voli Universitas Pamulang.

## Cara pakai
1. Buka `index.html` di browser untuk preview.
2. Edit nomor WhatsApp di bagian JavaScript:
   `const whatsappNumber = "6281234567890";`
3. Ganti jadwal, prestasi, dan tautan media sosial sesuai data resmi UKM.

## Hosting gratis
Folder ini bisa diunggah ke layanan hosting statis gratis seperti GitHub Pages atau Netlify.
Tidak membutuhkan database atau server.
